# NA70 固定点转台建图：相似项目与开源方案清单

更新时间：2026-09-15。以下项目按“与当前硬件/算法的接近程度”排序；仓库内容、许可证和依赖版本在实际复用前仍需再次核对。

## 1. 最直接相似：旋转平台 LiDAR

### StaticScan / pointcloud-reconstruction

- 项目：[tthom289/pointcloud-reconstruction](https://github.com/tthom289/pointcloud-reconstruction)
- 类型：旋转平台 VLP-16 离线重建。
- 关键流程：`offline_deskew.py` 使用平台编码器角度按点时间去畸变；`icp_merge.py` 将完整扫描切成有重叠的角度片，用 ICP 合并；`flythrough.py` 查看结果。
- 关键输入：ROS 2 MCAP、`/velodyne_points`、`/rotating_platform/angle`、编码器角度时间戳、旋转中心、安装 RPY、角度偏置和方向。
- 关键参数：旋转轴、旋转中心、角度偏置、是否反向、编码器与 LiDAR 时间偏移、切片数量、重叠比例、ICP 接受阈值。
- 与 NA70 的相似点：几何变换和数据流几乎是当前目标的直接先例。
- 与 NA70 的差异：VLP-16/MCAP/ROS 2 数据格式不同，项目默认有编码器角度；不能直接读取 NA70 PCAP。
- 可借鉴：数据 schema、角度插值、去畸变、角度切片、链式 ICP + 二次精化、viewer 设计。
- 不应直接复制：协议解码、点时间假设和 VLP-16 轴定义。

## 2. 非重复扫描 LiDAR 官方工程

### Livox Mapping

- 项目：[Livox-SDK/livox_mapping](https://github.com/Livox-SDK/livox_mapping)
- 类型：Livox 小视场低速建图，支持多个 Livox LiDAR。
- 关键点：针对小 FOV、不同特征提取和低速 mapping；提供 ROS bag 示例并输出 PCD。
- 与 NA70 的相似点：非重复扫描、小视场、需要多帧覆盖。
- 局限：ROS1/旧版依赖，默认不是固定转台角度方案；不能解决缺失编码器角度。

### Livox Cloud Undistortion

- 项目：[Livox-SDK/livox_cloud_undistortion](https://github.com/Livox-SDK/livox_cloud_undistortion)
- 类型：LiDAR 点云运动去畸变。
- 关键点：使用 IMU 处理旋转失真，并将 Livox 数据适配到 PointCloud2。
- 与 NA70 的相似点：明确把“点云不是同一时刻快照”作为问题。
- 局限：依赖 IMU；当前 NA70 数据没有逐点时间和 IMU，不能照搬。

### Livox Automatic Calibration

- 项目：[Livox-SDK/livox_automatic_calibration](https://github.com/Livox-SDK/livox_automatic_calibration)
- 类型：基于刚性结构一致性的 LiDAR 外参自动标定。
- 关键点：先用 base LiDAR 建图，再让 target LiDAR 注册到地图，利用刚性几何约束迭代优化。
- 与 NA70 的相似点：可以作为未来“用固定结构校验角度/外参”的参考。
- 局限：目标是多 LiDAR 外参，不是转台旋转角度；需要足够共同可见结构。

## 3. 通用 LiDAR 里程计/建图项目

### FAST-LIO / FAST-LIO2

- 项目：[hku-mars/FAST_LIO](https://github.com/hku-mars/FAST_LIO)
- 论文：[FAST-LIO2](https://arxiv.org/abs/2107.06829)
- 类型：紧耦合 LiDAR-IMU 里程计与增量地图。
- 关键点：原始点直接注册、ikd-Tree、支持旋转多线和 Livox 固态 LiDAR，也支持 ARM。
- 与 NA70 的相似点：可以作为未来 Jetson/ROS2 真实移动路线的候选基线。
- 当前不可用原因：没有 IMU 和同步时间；固定点转台 V0 不应以它替代外部角度。

### KISS-ICP

- 项目：[PRBonn/kiss-icp](https://github.com/PRBonn/kiss-icp)
- 论文：[KISS-ICP](https://arxiv.org/abs/2209.15397)
- 类型：LiDAR-only 点到点 ICP 里程计。
- 关键点：恒速预测、自适应阈值、鲁棒核、体素子采样，参数少。
- 与 NA70 的相似点：可以作为无 IMU 的几何可观测性诊断和小范围残差验证。
- 当前局限：需要足够重叠和可观测结构；不能从无角度 PCAP 中可靠推断大转台角度。

### LOAM / loam_livox

- 论文：[LOAM 作者/CMU 页面](https://publications.ri.cmu.edu/loam-lidar-odometry-and-mapping-in-real-time)
- Livox 版本：[loam_livox](https://arxiv.org/abs/1909.06700)
- 类型：特征提取、里程计和地图分层建图。
- 与 NA70 的相似点：处理扫描时间差、将高频运动估计与低频地图匹配分开。
- 当前局限：是移动平台路线，不是已知转台角度的固定点融合。

## 4. 多视角配准/外参工具

### Open3D Multiway Registration

- 官方文档：[Open3D multiway registration](https://www.open3d.org/docs/latest/tutorial/pipelines/multiway_registration.html)
- 类型：多点云位姿图、相邻 ICP、回环边和全局优化。
- 可借鉴：已知初始位姿作为 pose graph node；局部 ICP 只做精化；信息矩阵和不确定边分开；最终体素下采样导出。
- 当前定位：适合真实角度外部变换之后的多视角一致性和未来回环，不适合当前无角度数据的大范围盲搜。

### ethz-asl/lidar_align

- 项目：[ethz-asl/lidar_align](https://github.com/ethz-asl/lidar_align)
- 类型：利用 6-DOF 外部位姿传感器求 LiDAR 外参。
- 关键点：先粗略角度全局优化，再做局部 6-DOF 精化。
- 与 NA70 的相似点：外部位姿先验 + 小范围优化的工程纪律。
- 局限：要求外部 pose sensor；当前角度日志和转台标定尚未实测。

### Pana1v/polka

- 项目：[Pana1v/polka](https://github.com/Pana1v/polka)
- 类型：ROS2 多源点云合并与 IMU 去畸变。
- 关键点：支持每个源独立 IMU、TF 和 articulated turret；可对旋转炮塔 LiDAR 做各自运动补偿。
- 与 NA70 的相似点：明确建模“旋转关节/炮塔”而不是假设传感器刚性固定。
- 局限：依赖 ROS2/IMU/TF，当前只能作为未来扩展参考。

## 5. 工程辅助项目

### Foxglove VLP-16 rotating scanner example

- 文章：[Turning a VLP-16 Into a “Spherical” Scanner](https://foxglove.dev/blog/turning-a-vlp-16-into-a-spherical-scanner)
- 关键点：编码器角度按包时间插值，先把点旋转到公共参考系；强调旋转平台地图质量本质上是同步问题。
- 价值：提供易懂的工程验证思路和可视化反馈。
- 证据等级：工程文章，不等同于同行评审论文。

### MGX3D Automatic Turntable

- 项目：[MGX3D/Turntable](https://github.com/MGX3D/Turntable)
- 类型：高精度重载转台硬件。
- 价值：可参考机械刚度、步进控制、重复性和长时间旋转设计。
- 局限：主要面向 Kinect/物体扫描，不是 NA70 操场 LiDAR 算法。

## 6. 复用优先级

| 优先级 | 项目/论文 | 复用内容 | 不能复用的部分 |
|---:|---|---|---|
| P0 | StaticScan / pointcloud-reconstruction | 角度日志、去畸变、角切片、ICP 合并 | VLP/MCAP 协议和点时间假设 |
| P0 | Claer et al. 2019 | 偏心旋转外参标定、旋转/平移解耦 | 球形标定靶假设 |
| P1 | Spin-LOAM | 自适应累积和旋转平台实验指标 | IMU/编码器/回环完整链路 |
| P1 | Livox 官方非重复扫描资料 | 覆盖率与积分时间统计 | Livox 参数不能当 NA70 参数 |
| P2 | KISS-ICP | LiDAR-only 小范围验证 | 不能当大角度姿态来源 |
| P2 | Open3D | 多视角 pose graph 和导出 | 当前不应让全局优化掩盖错误角度 |
| P3 | FAST-LIO2/LIO-SAM/polka | 未来 IMU/ROS2/Jetson路线 | 不是当前 V0 前置条件 |

# YESENSE 本机实时监视器

项目内位置：`tools/imu_live/`（自 `.codex` 可视化目录收编的完整可运行副本，`photos/` 已随项目保存；源码快照与 2026-10-30 真实静置报告另存于 `Plan/evidence/slam/20261030-imu-mounting/`）。运行时新产生的静置报告写入本目录 `evidence/`，`__pycache__`、`server*.log` 为本机缓存不入库。

装配模型与静置检查：http://127.0.0.1:8770/model 。外壳宽×深×高为用户提供的 90×130×110 mm；IMU 可视中心、板卡尺寸及局部外形均是照片粗估。支持三视图、旋转缩放、相对姿态示意、OBJ 和模型 JSON 导出。模型基准是外壳中心，并非已确认的雷达光学原点。导出参数中的 T_IL、time_offset_s 保持 null，不可用于融合。

静置检查以主机接收时间采集 10 秒，在 `evidence/` 保存原始有效帧 JSONL 和带 SHA-256 的报告。它只检查短时静置一致性，给出条件性的陀螺零偏候选和重力倾角；不修改传感器配置，不校正实时原始数据。开发阈值在 `calibration.py` 明确列出，不代表厂家精度验收。单姿态不能估计完整加速度偏置/比例因子、绝对 yaw、雷达—IMU 外参或时间偏移。

2026-10-30 实测：第一次采集因 Windows 串口重连配置失败得到 0 样本，失败报告保留。用户重新插拔后，第二次 2007 帧、10.032 秒、199.960 Hz，无帧序号中断、无数据完整性错误，静置一致性检查符合开发阈值。Roll=-0.03689°、Pitch=0.78530°，是由加速度推得的重力倾角，包含未建模的偏置/尺度影响，不是安装外参。未输出设备采样时间戳。报告 `evidence/static-20261030-131253.json`；时间标签由执行主机时钟生成，仅作文件标识。

验证：分片真实帧解析、损坏校验重同步与载荷越界拒绝；合成静置/运动/短窗/输入错误/空输入；实时 HTTP、增量游标、CSV；浏览器三视图切换及 JSON/OBJ 下载。所有 SYNTHETIC 检查仅验证程序逻辑，真实静置报告独立保存。下载导出已复制至本目录 `na70-yesense-model.json` 和 `na70-yesense-approx-mm.obj`。

启动：在此目录运行 `python monitor.py`，然后打开 http://127.0.0.1:8770 。也可在 PowerShell 运行 `./start.ps1`。依赖 `pyserial`（当前本机已安装）。停止服务：终端 Ctrl+C。

默认 COM12、460800、8N1。可通过 `--port COM12 --baud 460800 --http-port 8770` 更改。HTML 需通过采集服务访问，直接双击不连接串口。

只监听 127.0.0.1，不发送设备指令；断开自动重试。最多缓存 6000 个有效帧，CSV 导出当前缓冲，非持续录制文件。暂停只冻结显示。频率、趋势横轴均使用主机接收时间，USB 批量到达会产生抖动，不代表设备采样精度或雷达同步。

根据 https://github.com/HViktorTsoi/yesense_ros_driver/blob/master/src/analysis_data.c 和 analysis_data.h 核对：0x10 加速度 m/s²、0x20 角速度 °/s、0x40 欧拉角 pitch/roll/yaw（°）、0x41 四元数，各 int32 × 1e-6；0x51 设备采样时间 μs。每帧独立解析，未输出字段显示缺失，不沿用历史值。校验失败及载荷越界的帧被拒绝。姿态模型仅作变化示意，具体硬件型号、安装外参及同步仍待确认。

安装布局修正：按用户确认，IMU 位于尾部顶面中线（默认 I*=[-35,0,60] mm，X/Z 仍粗估）；大接口位于 +Y LEFT 侧。左侧视从 +Y 看向机身，接口在画面左下角（+X、-Z）。接口具体中心、局部尺寸仍为示意，不构成外参。页面默认值及本目录 JSON/OBJ 同步更新。

后续用户更正：大接口改为 +Y 左侧视图右下角（-X、-Z）；IMU 继续沿 -X 后移，默认 I*=[-43,0,60] mm。后移 8 mm 是可视粗调，非实测。JSON/OBJ 已同步。

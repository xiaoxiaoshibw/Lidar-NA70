# NA70＋YESENSE 安装记录与内外参测试流程

执行入口已细化为 [标定 AI 执行计划](../Plan/NA70_YESENSE_标定AI执行计划.md)：AI 负责软件和计算，用户仅按 [采集卡](../Plan/NA70_YESENSE_用户采集卡.md) 逐批测量录制。本文作为技术依据保留。

日期：2026-10-30（Asia/Shanghai）。阶段：S0–S2 准备。本文记录已确认的机械布局、USB 实测与建议测试流程；完整标定、同步和 NA70 LIO 仍为 `NOT_EVALUATED`。

## 1. 当前安装与实测事实

- 用户提供外壳宽×深×高为 **90×130×110 mm**；未取得厂家机械图及测量公差。
- IMU 位于**尾部顶面中线**，后续又按用户要求向尾部（X 负方向）移动模型。
- 雷达外壳下方大接口位于 **+Y LEFT 侧**；从 +Y 看向机身时，在画面**右下角**。这是用户更正后的最终布局。
- 可视模型 B 系：外壳几何中心为原点，X 朝光学窗外，Y 向左，Z 向上。B 尚未与雷达实际点云轴系、光学原点对齐。
- 模型 IMU 板卡可视中心暂取 `[-43, 0, 60] mm`。Y=0 对应用户确认的中线；X/Z 及板卡尺寸仍是可视粗估。后移 8 mm 是软件调图值，不是用户实测位移。
- 可视板卡中心不等于惯性测量原点。**不可把上述向量填入 T_IL；R_IL、t_IL、时间偏移仍未知。**
- 本机识别 CH9102 / COM12；460800、8N1 的连续数据符合 YESENSE 协议。YESENSE 的具体型号、量程与同步引脚能力仍待厂家资料确认。
- 当前监视器只读取串口，不向设备发送配置命令；设备数据单位按参考解析源码处理：加速度 m/s²、角速度 °/s，转换到 LIO 时角速度仅转一次 rad/s。
- 本地监视器：`http://127.0.0.1:8770/`；模型：`http://127.0.0.1:8770/model`。源码、模型快照及证据清单见 [本轮记录](../Plan/evidence/slam/20261030-imu-mounting/REPORT.md)。这不是主 WebUI 的生产标定模块。

静置尝试分开保留，不互相覆盖：

## 2. 测试对象必须分开

| 对象 | 参数/问题 | 如何测试 |
|---|---|---|
| 雷达内部测量几何 | 距离偏置/尺度、角度偏差、光学原点、扫描几何 | 已知距离与姿态的平面/靶标，多距离、多视场、留出测试 |
| IMU 内参 | 陀螺/加速度偏置、尺度、轴间误差、温漂/噪声 | 预热静置、六面静置、有角度基准的轴向转动；更复杂项目需工装 |
| 雷达—IMU 外参 | 相对旋转与平移 | 刚性安装，联合雷达＋IMU 多轴运动记录与离线优化 |
| 时间关系 | 偏移、漂移、USB 延迟抖动、雷达包时间语义 | 核实设备时间/触发能力，联合动态估计与误差预算 |

雷达不是相机，不套用相机 K/distortion 矩阵。距离码×16 mm、pitch 码×0.0258°、yaw 码×0.0432°是当前解码契约，不能为了让墙“变平”任意调这些常数。驱动中的整体 pitch/yaw offset 也不能被直接视为已知的本套 IMU 外参；记录来源和应用位置，避免重复旋转。

## 3. 推荐第一批：静态雷达测量验证

这是测试建议，尚未执行。距离/角度基准应比待验证误差更准确，记录其精度；没有已知真值时只报告平面一致性或重复性。

1. 确认整机刚性安装、连接线不会拉动 IMU；固定固件、解码配置和轴系。先取得厂家光学原点、角度/距离精度、最小量程与校准资料。
2. 在设备有效量程内，选择有独立距离基准的大平整墙面或硬质平板，例如条件允许时用 5/10/20 m，分别静止采集 20–30 s，每距离至少 3 次。靶面避开窗玻璃、反光镜和边缘混合回波。
3. 测的是**参考原点到靶面沿法向的距离**，不是随意量外壳到墙的斜距。光学原点未知时，可用外壳基准作相对距离增量测试；绝对截距中包含原点误差，不单独宣称测距零偏。
4. 按源时间和视场区域提取同一靶面；报告点到平面残差 RMSE、绝对残差 P95、法向距离偏差、视场分区差、强度和有效回波数。每个窗口保持同一积分时长，非重复扫描不伪造 ring/重复扫描周期。
5. 单独拟合平面的低残差不证明绝对测距或角度正确。通过独立测量的靶面姿态/位置，在视场中央、左右、上下及多个已知倾角测试角度几何；需要已知靶标方位或有角度基准的安装工装。
6. 先判断是否有系统误差。多距离偏差趋势可用于检验距离尺度/偏置模型，但先排除原点和测量基准误差。确需内部参数重标定时，使用厂家参数模型/接口或另立扫描模型适配任务，不能先放开大量未知参数一起优化。
7. 拟合与验证数据分开：例如部分距离/角度用于拟合，另留距离/角度检验；同一组墙面数据上“误差变小”不足以验收。

## 4. IMU 检查与机械外参初测

- 参考厂家预热要求；资料未到位前先记录上电时长，做 10–20 分钟静置作为工程基线，统计短窗均值漂移及噪声。当前 10 秒检查仅用于快速筛除明显运动。
- 对整机做六个已知方向的稳定静置，每面建议 20–30 秒，确认比力主轴约为 ±g，记录其他轴的分量。单姿态不能解完整加速度偏置；近似轴对齐的六面可估偏置/尺度，非正交与高精度需已知姿态工装/更多姿态。
- 绕整机 X/Y/Z 分别作可控正负转动，核对陀螺主轴、符号与交叉轴响应；若要标定尺度，需独立角度/角速度基准，不能只凭手感。记录 IMU 厂商轴到 B 系的候选旋转。
- 用厂家原点定义＋卡尺/机械图测量雷达光学原点到 IMU 测量原点的位移及不确定度，作为外参初值。外壳尺寸和板卡中心不足以替代该测量。

## 5. 第二批：联合时空外参标定

1. 同一次录制保存 NA70 原始 UDP/PCAP、包级设备/主机时间、IMU 原始帧和解码值、主机单调时钟、设备时间（如有）、丢帧/重连日志。旧 PCAP 与今天的 IMU 不能拼成同步运动会话。
2. 先解决时序输入：当前 IMU 未输出采样时间；核实是否可配置、触发/PPS 等能力。无硬同步时必须评估主机延迟抖动与时钟偏移/漂移，不能只把第一次到达时间对齐。NA70 包内测量时序亦待核实，现有推算 offset_time 不能冒充实测逐点时间。
3. 在能同时看到墙面、墙角、地面、立柱等多方向结构的场景录制。先静止 5–10 秒，随后温和三轴旋转＋多方向平移，改变运动方向和速率，再停稳。首轮每段约 60–120 秒、至少 3 次独立采集；这些是建议值，实际以激励/可观测性检查为准。
4. 只绕竖轴转圈或在平地匀速直行通常不足以约束全部参数。完整参数估计需检查弱方向，不能以优化器正常退出代替六自由度可观测。
5. 优先适配 LI-Init 做候选时空初始化。其上游为 ROS1/catkin 路径，并非现有 Humble 工程可直接启动；NA70 点云类型、扫描组织与时间必须先适配。OA-LICalib 供内外参联合方法对照，其公开多线激光模型也不能直接冒充 NA70 模型。
6. 统一 `p_I = R_IL p_L + t_IL`，T_IL 将 LiDAR 坐标变换到 IMU 系。t_IL 是雷达原点在 IMU 系中的坐标，与“IMU 在外壳中的位置”不是同一个向量。保存工具原始输出、正逆方向、单位、轴变换链及每个时钟域。

## 6. 独立验收与交付

- **重复性**：按现行 SLAM 计划，3 次独立标定旋转差≤0.2°、平移差≤2 cm 作为拟定重复性门；不是绝对准确度保证，不因重复性合格就通过全链。
- **留出动作**：另录一段未参与求解的运动。比较原始/仅旋转补偿/完整补偿下同一墙面、立柱的厚度、重影和残差，检查误差随距离/角速度是否放大。点集、时间窗、裁剪范围保持可比，不靠更强滤波“变薄”。
- **静止对照**：补偿不应给固定场景制造明显变形；去回程、正反转、不同速度的结构应一致。单看建图“好看”不足以通过。
- **误差预算**：按目标距离和容许误差冻结门槛。例如角度一项在 200 m 控制为 0.2 m，粗略需角误差≤0.057°（e≈rδθ）；上述 0.2°重复性门并不足以保证这一目标。时间、测距、外参平移等还需分别留预算。
- **落盘**：raw session、坐标/时间定义、机械测量、参数版本、T_IL/逆矩阵、时间映射与不确定度、软件 commit、优化残差、弱方向、3 次对照、留出验证和失败记录一并保存。
- **接入**：只有输入证据齐全后，才将参数填入 `tools/lio/preflight_default.yaml` 的会话副本，运行既有 `tools/prepare_lio_session.py`。预检通过只代表输入契约通过，不代表标定验收；当前默认文件保持未知值与拒绝门禁。

下一步优先做“雷达静止墙面基线＋联合原始采集/时钟核实”，而非直接用模型外参启动移动 SLAM。模型、球门、导线、转台历史验收状态不因此升级。

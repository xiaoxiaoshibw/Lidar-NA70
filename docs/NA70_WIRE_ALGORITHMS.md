# NA70 架空细线识别算法设计（设计稿）

版本：`wire-algorithms-v1-draft`  
日期：2026-09-25  
状态：算法与替换门禁已设计；未取得经复核的真实导线回波，所有识别能力均待实验验证。接口与模块边界见[软件架构](NA70_WIRE_ARCHITECTURE.md)，真值和指标见[调试验收契约](NA70_WIRE_DEBUG_ACCEPTANCE.md)。

## 1. 算法目标和硬门禁

目标是从非重复扫描 NA70 的稀疏原始测距中，输出**当前回波支撑**的有限架空线段、三维位置、方向、到雷达/机体的最近距离及观测年龄。仅有几何形状时类别为 `LINE_STRUCTURE` 或 `UNKNOWN_LINE`，不从点云推断高压等级。预测用于保持搜索连续性，不能升级为当前测量。

必须按[细线 W1–W5 计划](../Plan/细线回波验证与逐级开发计划.md)推进：

| 门禁 | 先回答的问题 | 算法可做的事 | 失败时的处理 |
|---|---|---|---|
| W1 | 独立测量的真实细线是否有可归属回波？ | 原始码、位置走廊、逐包出现和同机位无线背景对照；人工复核归属 | 记录 `NOT_EVALUATED` 或本条件 `FAIL`；不启动导线检出率或距离声明 |
| W2 | 哪些实测距离、线径、方向、窗口时长有重复支撑？ | 单帧、0.5/1/2/5 秒因果窗与来源统计 | 缩小已验证工作包络；200 m 仍为探索档 |
| W3 | 已知 ROI 内能否提取有限线段？ | 调用三维 RANSAC 基线并验证真实支撑 | 支撑不足、过短或残差/断裂超限时拒绝 |
| W4 | 无 ROI 能否自动提出线并排除困难背景？ | 投影线候选、三维模型复核、独立负例评分 | 保留误检和漏检案例，不靠降低门槛伪造通过 |
| W5 | 运动与实时条件能否输出新鲜测量？ | 有可信外参与位姿时补偿、关联和短期预测 | 无补偿/时钟质量不足的多包窗拒绝测量确认 |

W1 工具已实现，真实回波归属仍是 `NOT_EVALUATED`。[S0 报告](../Plan/evidence/thin-wire/20260924-s0-release/REPORT.md)中的几何交会只用于观察扫描机会，不能当作 W1 正例、传感器检出率或拟合器的真值输入。

`pyRANSAC-3D` 返回的是无限直线和内点索引。其实现使用 Python 全局 `random.sample`；适配器在隔离执行上下文中固定并记录种子，不让并发请求互相影响。实例的 `distances` 不能作为最佳模型最终残差，必须由返回的方向和线上点对所有原始候选重算。调用前过滤非有限/重复/退化点；返回原始 ID，不用库内索引取代 PCAP 身份。W1 实例的 5 秒窗口可含约 100 万条原始射线，拟合器每轮遍历输入点；W3 必须先限定 ROI，W4 必须先提议并限制候选规模。若为提速而抽样，记录规则和 seed，最终内点、覆盖与分母回到**全部原始候选**重新计算。

## 3. 数据与时间层

1. 解码后保留距离/俯仰/方位/强度原码、XYZ/intensity、原始帧/包/点 ID 和包级设备时间。距离码零表示当前协议下无有效测距；即使角码存在，也不能把该记录计为目标回波。距离码与两个角码均零时方向不可恢复，不据此推断目标未被扫描。
2. 窗口按设备包时间选择 `(T-duration,T]`，包括包的全部 200 条记录；与 [W1 契约](THIN_WIRE_W1_CONTRACT.md)一致。时间缺失、倒退或相邻包大间隔时断段。重叠窗共享原始记录，只能作为相关观测。
3. 固定机位保留完整原始有效点；算法可建立临时索引、候选掩码和展示抽样，但原始支撑统计及 W1 验收不得体素降采样或套球门距离/高度门限。
4. 全片回放采用按包或帧增量的有界 ring buffer，配置最大窗口时长、包数、点数和内存。现有 W1 `run_audit` 适用于少量指定窗口，不能直接作为逐帧生产循环。
5. 运动录制必须声明 `confirmed_static`、`moving_with_pose` 或 `moving_uncompensated`；只有实测外参、同步位姿与质量门通过的包可变换到共同坐标。仅有帧级姿态不能声称逐点去畸变。未补偿的多包窗口只进入诊断。

## 4. W3：人工 ROI 线段基线

人工 ROI 只裁剪搜索空间，拟合器不可读取真值端点作为输出。流程如下：

```text
原始有效回波 → 人工 ROI mask → 有界 pyRANSAC-3D Line.fit
→ 以最佳模型重算所有点正交残差和内点 → 有限支撑区间
→ 空间/时间/背景证据门 → LineMeasurement 或明确拒绝原因
```

设拟合方向单位向量为 `d`、线上点为 `q`，候选原始点为 `p_i`。正交距离 `r_i = ||(p_i-q) × d||`，沿线坐标 `s_i = (p_i-q)·d`。报告内点 `r_i` 的 RMS 与 P95，并将 `s_i` 划入预先固定宽度的沿线区间。分别输出：

- 支撑点总数、唯一 `(capture,frame,packet,point)` 数、不同包/帧数及独立时间段数；相同原始点出现在多个重叠窗口时不重复计确认。
- 首末实测支撑点投影跨度、**实际有支撑区间占比**、最大内部无支撑缺口、原始线段以外的外推长度。首尾跨度不是覆盖长度；拟合直线的数学无限延伸不是实测线。
- 距离/残差分布、原始强度分布、最近来源年龄和坐标/运动质量。强度未标定，只能作为同设置下的辅助诊断，不能单独判类别。
- 对同机位目标移除背景和树枝/围栏等负例的同配置拒绝结果。若原始支撑不足、退化成单团块、连续覆盖缺失或背景同样产生线，输出拒绝或 `UNKNOWN_LINE`。

具体最小来源数、残差半径、沿线箱宽、允许缺口、窗口时长都从 W1/W2 开发录制的噪声与独立标注误差确定，并在独立验证前冻结到导线 YAML。设计稿不预填“通用可用”的数值阈值。

## 5. W4：无 ROI 提议与曲线扩展

首个可对照的全视场提议方案：按标定后的雷达前向轴，把有效点投到归一化角平面 `u=横向/前向`、`v=竖向/前向`，保留每个栅格背后的原始点列表和距离层；在占据图上调用 `HoughLinesP` 得到有限的二维提议，再回取原始三维点执行 W3 的拟合与支撑验证。栅格宽度和允许断裂来自真实开发数据；图像形态学补线只能用于**提议**，补出的像素不能算雷达支撑。方位/俯仰码步长不是光斑尺寸，也不直接作为像素和检出阈值。

全场提议同时保留可对照基线：高度/空间隔离筛选、条件满足时的局部 PCA 线性度。后者需报告邻域点数，不足时标 `insufficient_neighborhood`，不能把高线性度当电线类别。Hough、PCA 与简单几何提议在同一冻结验证集比较真实召回、每分钟误报、来源覆盖与耗时，然后保留有证据支持的方案。

只有长线段显示系统性垂度、直线模型残差与位置分布支持时，才用 `scipy.optimize.least_squares` 的稳健损失拟合分段曲线或悬链线。曲线模型必须同时报告参数可辨识性、相对直线的独立验证收益和真实点覆盖；两端无回波时延伸部分仅标预测，不用于“测得最近距离”。

## 6. W5：关联、预测与输出新鲜度

固定机位可按线段位置、方向、空间重合与来源年龄进行门控关联。移动机位先对合格的包级观测做实测位姿转换，再关联到共同坐标；不恢复已证伪的无 IMU 纯点云里程计作为默认补偿。借鉴球门跟踪器的状态和证据新鲜度规则，但导线状态、几何门与阈值独立。

- `MEASURED_CURRENT`：当前允许窗口内有原始回波支撑、几何和运动质量通过；输出线段、最近距离及最新支撑时间。
- `PREDICTED_RECENT`：只维护候选轨迹和搜索范围，显示预测年龄；不能计入测量层 TP，也不能作为新的实测避障距离。
- `NO_CURRENT_MEASUREMENT`：此时无可接受当前线测量；与“目标不存在”分开。
- `UNOBSERVABLE`：扫描方向、时间、位姿或输入质量不足以判断；不能把它计作可靠阴性。

对机载告警，设飞行速度为 `v`、观测等待与处理总延迟为 `T`，飞行期间消耗距离为 `vT`；还需单列测距、姿态、外参与控制余量。先从实测工作包络和任务所需提前距离倒推允许 `T`，再选择窗口，不把静态 5 秒累积能力当实时能力。

## 7. 参数与替换条件

导线配置独立于 `goal_detection.yaml`，至少版本化 `window`、`direction_quality`、`roi/proposal`、`line_fit`、`support_validation`、`motion`、`tracking`、`resource_limits`。每个数值配置连同内容哈希写进运行清单，非法、空、NaN、无效时间与资源超限都生成显式状态。参数只用开发录制校准，独立验证前冻结；任何验证后改阈值都提升版本并重新运行整套验证。

`pyRANSAC-3D` 是首版可替换基线。出现以下已复现问题才替换其后端：同一输入固定 seed 仍无法复现、退化输入无法被适配层安全拒绝，或 Jetson 上拟合耗时/资源超过事先定义的预算。PCL 替换后，来源内点、有限区间、状态与评分的外部契约保持不变；算法差异以逐窗 A/B 证据报告，而非只报总体速度。

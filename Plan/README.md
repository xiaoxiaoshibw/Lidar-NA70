# NA70 固定俯视激光雷达移动目标感知计划

版本：v1.0  
日期：2026-09-08  
部署目标：Jetson Orin Nano 4GB + ROS2 Humble

## 1. 最终目标

从 NA70 连续点云中找出移动点，将移动点聚类为目标并建立稳定轨迹，再从原始完整点云中裁剪每个轨迹对应的目标区域，识别目标类型。

```text
NA70 PointCloud2
  ├─ 背景减除 → Moving Points → 聚类 → 跟踪 ──────────┐
  └─ 原始完整点云 → 按 Track 裁剪 ROI → 多帧累积 → 分类器 ┤
                                                     ↓
                                  类别 + 位置 + 速度 + 轨迹
```

## 2. 固定技术路线

1. 使用体素背景减除发现移动点。
2. 使用 DBSCAN 将移动点变成目标实例。
3. 使用 Kalman Filter、门控和 Hungarian 匹配建立 Track。
4. 使用 Track 的空间范围从同时间戳原始点云裁剪完整 ROI。
5. 累积同一 Track 最近 3～5 帧，交给轻量点云分类器。
6. 对类别概率做 Track 级时序平滑，输出统一目标。

## 3. 重要边界

- MapMOS 不再作为主线。现有试验只证明官方预训练方案在当前 NA70 数据和配置上失败，不能写成“静止雷达在原理上无法使用 MapMOS”。
- 分类器不直接消费残缺的 Moving Points；Moving Points 只用于定位目标 ROI。
- 第一阶段只识别发生过运动的目标。若以后必须识别长期静止的人或车辆，再增加完整点云 3D Detector 支路。
- Windows 负责代码编辑、离线数据处理和纯逻辑测试；本机计划使用安装在D盘的WSL2/Ubuntu 22.04 + ROS2 Humble验证节点、Topic和PCAP回放；Jetson/Humble负责最终ARM构建、真雷达、性能和系统验收。
- 虚拟数据只用于逻辑回归，所有效果结论必须由真实 NA70 数据支持。

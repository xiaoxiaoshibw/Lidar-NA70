## 4. 对原始设想的修正

1. 左、中、右不是三张已知外参的静态地图。左、右录制期间雷达在旋转，点云处于不同传感器坐标系；未知角度下直接拼接会制造重影。
2. 移动 PCAP 可以用于离线等速回放和算法开发，但它不是“实时输入”证据。实时验收还需要 UDP/ROS2 在线链路、时限、积压和断流测试。
3. 现场当前主要是共面远场几何。若雷达保持水平、固定高度移动，应优先求解 `SE(2)` 的 x/y/航向；无 IMU 的自由手持 `SE(3)` 在当前观测条件下不可承诺。
4. 没有外部路线真值时，只能评价内部一致性、失锁、回环残差和地图重影，不能报告绝对轨迹精度。外部真值仅用于验收，不参与算法估计，不违反“无 IMU SLAM”配置。

## 5. 当前数据角色

- `zhong2`：固定视点平面/重复扫描基线，以及操场中心外观参考；不能单独代表完整操场地图。
- `zuo`、`you`：旋转建图和视场覆盖实验集；须先解决覆盖驱动成帧、时变姿态和跨段配准。
- `yidong`：真实平移失败回归集；用于定位空帧、平面退化、连续跟踪和恢复问题，不作为当前 R7 通过证据。
- 五张照片：地标候选、采集方向和地图可视化核查参考；在标定缺失时不做视觉—雷达融合。

结论：数据足以启动针对性研发，但不足以直接生成可信操场地图或证明实时 SLAM。下一阶段首先修复数据表示和可观测性判定，再决定受约束 `SE(2)` 是否可行；完整 `SE(3)` 与完整 SLAM 必须经过独立门禁。

# 按 IMU 每 1° 分批与包级旋转补偿

2026-11-05，Windows 本机 Python 3.12.10。真实输入 20261105-162734-639900，输入与源码哈希、参数见 metrics.json。复用唯一 PCAP 解码器，不新增配准算法。此前球门/转台/SLAM 验收状态不变。

处理全部 573 个雷达分组，共 11,457,000 条射线。诊断规则排除距离码0及距离/角度码65535（厂家语义仍未确认）；20 m 内共 1,242,348 条回波进入建模，401 条更远回波计数但未建模。对每个雷达包的主机接收时间插值 IMU 航向，包内200点使用同一时间，不伪造设备逐点采样时间。相对航向先解除 ±180° 跳变；每点按最近整数角度分组，例如45°组覆盖[44.5°,45.5°)，旋转时仍使用实际包时刻航向而不是45°。

有效回波对应航向约 -0.09°～153.24°，形成0～153°共154批，无空批。设备其他时刻的航向覆盖不等于存在有效雷达回波。每批保留传感器坐标点云、假设参考系点云及局部三角网格；原始回波和帧/帧内点索引、原始码、主机时间和实际角度保存在 source_observations.npz，可回查源包与源点。各批累计显示约35.8万个体素点（含跨批重复）、约38万个局部三角面；合并后再次5 cm体素化得到197,854点，统一滚球网格89,035三角面。index.html显示逐批网格累计，不将其点数误当全局去重后点数。

三维页面可逐度播放、单度/累计切换、独立开关点云及表面。0°包含前20秒静止段及角度仍接近0°的观测，分组并非等时长。152°只有62条有效回波，不能通过补点冒充覆盖充分。颜色为参考坐标Z，未确认重力竖直方向。

## 运动畸变诊断

当前数据中每帧所选回波的包时刻航向跨度中位0.164°、P95 0.820°、最大1.387°。将每帧包时刻航向范围中点当统一角度，与包时刻角度变换对比，点位置差中位约1.46 cm、P95 5.94 cm、最大20.39 cm。这是两种处理近似之间的差异，不是独立真值测出的畸变或补偿精度，见 motion-distortion.json。

分批本身不等于去畸变。本实现包含包级旋转补偿，但仍假设IMU航向绕雷达Z轴、正号、原点不平移；未通过外参、时钟或坐标轴验证。包内逐点运动与平移均未补偿，不能宣称完整去畸变或可信教室尺寸。三面墙归属尚未验证。

# IMU 波动频谱初步诊断

2026-10-30 用户补充：雷达工作时本身会振动，雷达升温也会影响 IMU 准确度。两者应作为实际工作条件研究；不凭静置阈值不通过就认定硬件故障，也不能把冷态标定结果直接用于热态。

按 IMU 帧序号计算 Welch 频谱，名义输出率假设 200 Hz、每段 1024 样本。设备采样时间不可用，因此下面的频率是名义近似，可能存在混叠或偏差，不证明机械振源：

| 输入 | 帧数 | 陀螺 Y/Z 标准差（单位 deg/s 为推断） | Y/Z 最强名义峰 |
|---|---:|---:|---:|
| 历史短时静置 `static-20261030-131253` | 2007 | 0.054 / 0.042 | 18.75 / 33.98 Hz |
| 工程会话 `20261030-155552` | 12018 | 0.754 / 0.789 | 53.52 / 53.52 Hz |
| 工程会话 `20261030-163303` | 12020 | 0.865 / 0.781 | 53.52 / 53.52 Hz |

历史和工程记录的安装、供电、温度等条件未完全对齐，比较不能作为因果实验。两段工程数据均出现相近频率峰，支持后续设计同安装条件下的可控对照；不能证明峰值来自雷达，也不能推断温度系数、滤波后误差或标定精度。未测到设备内部温度，表面温度也不能当芯片温度。执行计划将记录预热时间、可测温度和温度测点/精度，冷态与工作态分别验收。

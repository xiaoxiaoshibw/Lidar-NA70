# 室内空场实测观测模型（2026-10-13）

用户要求：根据空场雷达会话量取点到雷达的距离，构建粗略空场模型并标记尺度；照片左侧人体忽略。

本轮为独立室内诊断产物，不修改 radar 足球门主线或 ldiar 生产/其他会话正在开发的文件。

## 交付

- `viewer.html`：自包含、离线可打开；三维旋转、俯视/侧视、1 m 网格、水平距离圈、回波持久性显示、点选斜距和两点测距。
- `scene.ply`：35,791 个真实观测体素中心，单位米，现有配平坐标。
- `scene.npz`：完整体素中心、平均原始斜距、出现帧数、回波数、代表源点索引/帧、R/T。代表点是溯源样例，不等于该体素所有点成员表；原始会话保留完整 intensity/ring/timestamp 和点序。
- `manifest.json`：输入哈希、来源、参数和边界。
- `preview.png`、`browser_check.json`：Windows 本机 Edge 浏览器检查结果。

## 照片与用途边界

照片可见地板、桌面、隔板和杂物，左侧人体不作为背景。当前旧空场与照片的同布局、相机外参、家具对应尚未验证，因此本轮不从照片猜测物体米制位置，不伪造墙面/桌面网格，也不补不可见几何。交付的是空场观测点云模型，不是闭合网格或完整房间重建。

后续顺序：

1. 当前会话与空场做同坐标检查/背景静态锚点对齐；失败不得直接扣除。
2. 冻结背景，保存原始、背景匹配、地面相关和候选点的删除归因。匹配阈值由空场噪声和独立留出帧确定。
3. 地板作为高度基准；倒地/躺下点靠近地面，不能以固定高度把整个人删去。人体邻域暂停背景更新。
4. 真实时序提取高度分位数、展宽、中心下降速度、低姿态持续时间和可观测性。模型空间可辅助生成位置/遮挡变化，但模拟雷达点必须标 SYNTHETIC；光滑家具网格不能替代真实稀疏回波。
5. 按会话/日期/人物切分数据，在真实留出序列核验人物保留、家具误检和动作分类。骨架可选，未经核验的骨架不当真值。

# 固定视点静态地图分段一致性观察

**日期：** 2026-09-28  
**状态：** `DEVELOPMENT / OBSERVED_ONLY`  
**环境：** Windows 本机，Python 3.12

## 输入与方法

输入为 `radar_capture_data/2/9.14_caochangzhong2.pcap`，SHA-256：
`2caa68d6491cb2ba6fd9bae86e04104038fbbf4c7a4e349fa6dcc211adc743ce`。

使用正式 NA70 解码器分别解码帧 0–99 和 100–199，并分别调用 `run_fixed_scene` 生成独立固定视点地图；地图体素尺寸均为 0.25 m。对每张地图用 `np.linspace` 的等间隔索引抽取 20,000 个体素，以 cKDTree 查询另一张完整地图的最近邻；反向再做一次，合并得到 40,000 个对称距离。精确体素 Jaccard 按两张地图的体素键集合计算。

## 观察结果

| 指标 | 结果 |
|---|---:|
| 第一段体素数（帧 0–99） | 114,341 |
| 第二段体素数（帧 100–199） | 115,621 |
| 最近邻距离中位数 | 0.1100771444 m |
| 最近邻距离 P95 | 0.4685111476 m |

该对照显示相邻 10 秒分段地图在点集层面有较高近邻重合，同时精确体素键并不完全一致。

## 结论边界

结果仅为固定视点重复观测的 `DEVELOPMENT / OBSERVED_ONLY` 稳定性观察。全视场距离受地面点和覆盖范围主导；没有独立测量的场景几何，也没有实测位姿。因此几何准确度与 ghosting acceptance 均为 `NOT_EVALUATED`，这些距离比例和 Jaccard 不构成准确率、无重影或建图验收结论。

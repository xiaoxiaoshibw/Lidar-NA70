# WebUI：PCAP 三维点云回放

日期：2026-09-09。范围由用户确认：Windows 本机服务、浏览器三维展示、首版仅离线 PCAP 回放；企业上位机用于功能参考，采用新的中文 WebUI。

## 已交付

- `../web/start.ps1`：Python 3.12 环境、依赖锁定、前端构建、本机服务与浏览器启动。
- React／TypeScript／Three.js：真实点云、鼠标观察、标准视角、时间轴、播放速度、着色、显示过滤、叠加和渲染预算。
- FastAPI：流式导入、后台索引、元数据、分页帧索引、Float32 二进制帧、取消／删除和重启恢复。
- 与当前 ROS2 驱动对齐的独立解码器，包括 16 mm 距离分辨率、安装坐标映射和整组角度偏移。
- 使用真实 `1.pcap`／`2.pcap` 的完整解码、随机读取、浏览器回放及实际 ROS2 PointCloud2 对比。

## 验收状态

W1：PASSED。详细命令、输入哈希、设备、指标、限制和截图见 `../web/VALIDATION.md`；使用说明与 API 协议见 `../web/README.md`。

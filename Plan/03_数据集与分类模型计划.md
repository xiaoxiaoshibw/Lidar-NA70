# 03 数据集与分类模型计划

## 1. 数据场景

每个类别至少覆盖不同距离、方向、速度、遮挡和目标数量：

| 场景 | 必需内容 |
|---|---|
| 空场景 | 无人、静态设施、树叶和环境噪声 |
| Person | 步行、跑步、停下、转向、多人交叉 |
| Bicycle | 推行、骑行、停下后启动 |
| Vehicle | 不同方向和速度，部分遮挡 |
| Other | 手推车、动物、飘动物体、无法判断的簇 |

每段录制保存原始 PointCloud2、运行配置、场景说明、类别、目标数量和采集时间。

## 2. 标注单位

以 Track 为主要标注单位，不逐帧重复标注同一目标。Track 样本至少记录：

```text
recording_id
track_id
class_name
start_stamp / end_stamp
quality: GOOD / PARTIAL / BAD
notes
```

边界不清、严重遮挡或聚类错误的样本进入 `OTHER/UNKNOWN` 或排除列表，不能强行赋类。

## 3. 数据切分

- 训练、验证和测试必须按 `recording_id` 切分。
- 同一目标连续轨迹不得跨集合。
- 测试集在模型选择完成前冻结。
- 类别不平衡时优先补采数据，再考虑加权损失。
- 虚拟数据单独标记 `SYNTHETIC`，不得进入真实测试集。

## 4. ROI 预处理

1. 从原始完整点云裁剪扩张后的 Track AABB。
2. 使用 Track 预测位置对多帧点云做平移补偿。
3. 坐标变换为目标中心相对坐标。
4. intensity 使用真实数据统计量归一化。
5. 点数不足时重复采样并附带有效点 Mask；点数过多时分层或随机采样。
6. 保存未经归一化的原始 ROI，保证后续可重新处理。

## 5. 模型路线

### M0 规则基线

使用长宽高、点数、高度分位数、反射率统计和速度。作用是验证数据质量和类别可分性，不作为最终模型上限。

### M1 传统机器学习基线

使用 Random Forest 或梯度提升树训练结构化 Track 特征。必须保存特征版本、训练配置和混淆矩阵。

### M2 轻量点云分类器

第一候选为小型 PointNet 类网络：

```text
点特征分支：N × 4 → Point Encoder → Global Feature
Track 特征分支：尺寸、点数、速度 → MLP
融合：Concat → MLP → Class Probabilities
```

只有在 M2 明显受局部几何表达限制时，才评估 PointNet++、DGCNN 或更重模型。

## 6. 类别稳定策略

- 单帧概率按 Track 做指数滑动平均或最近 K 帧加权投票。
- 新 Track 在积累足够帧前输出 `UNKNOWN`。
- 最高概率低于阈值时输出 `UNKNOWN`。
- 类别切换设置滞回阈值，避免 Person/Other 来回跳变。
- Track 丢失后重新创建，不继承旧类别，除非完成明确的 Re-ID。

## 7. 评估指标

| 层级 | 指标 |
|---|---|
| 移动点 | 候选点 Precision/Recall、空场景误报点率 |
| 聚类 | 目标召回率、误簇、拆簇、合簇 |
| 跟踪 | ID Switch、Track Recall、轨迹连续率、速度误差 |
| 分类 | 每类 Precision/Recall/F1、Macro-F1、混淆矩阵、UNKNOWN 比例 |
| 系统 | 端到端延迟、帧率、峰值内存、掉帧率、长测稳定性 |

# 01 系统架构与接口

## 1. 输入基线

| 项目 | 当前约定 |
|---|---|
| 输入 Topic | `/inno_lidar_cloud` |
| 消息类型 | `sensor_msgs/msg/PointCloud2` |
| 必需字段 | `x, y, z, intensity`，FLOAT32 |
| 频率 | 约 10 Hz |
| 点数 | 当前回放约 20000 点/帧 |
| QoS | `SensorDataQoS`，BEST_EFFORT |
| 坐标系 | 第一阶段统一使用固定雷达坐标系；不得仅改 `frame_id` 冒充坐标变换 |
| 时间 | 必须单调递增；各下游输出继承输入 stamp |

## 2. ROS2 包结构

```text
ROS2/src/
├── double_wedge_driver/          # 现有驱动
├── na70_perception_msgs/         # Cluster、Track、ClassifiedObject 消息
└── na70_perception/
    ├── na70_perception/
    │   ├── background_subtraction_node.py
    │   ├── moving_cluster_node.py
    │   ├── multi_object_tracker_node.py
    │   ├── track_roi_node.py
    │   └── object_classifier_node.py
    ├── config/perception.yaml
    └── launch/moving_object_pipeline.launch.py
```

第一版使用 Python 快速完成正确性验证。性能不足的热点再迁移到 C++/PCL/CUDA，不提前重写全部节点。

## 3. 节点数据流

### 3.1 `background_subtraction_node`

输入：`/inno_lidar_cloud`  
输出：

- `/bg_subtraction/moving_points`：移动候选点云；
- `/bg_subtraction/moving_mask`：可选，原始点索引或布尔 Mask；
- `/bg_subtraction/diagnostics`：背景状态、点数、延迟和异常。

职责：字段检查、NaN/Inf 清理、ROI、体素背景模型、差分、邻域扩张和背景更新。

### 3.2 `moving_cluster_node`

输入：`/bg_subtraction/moving_points`  
输出：

- `/perception/moving_clusters`；
- `/perception/cluster_markers`。

每个 Cluster 至少包含：时间戳、临时编号、质心、AABB、长宽高、点数、平均反射率和高度分位数。

### 3.3 `multi_object_tracker_node`

输入：`/perception/moving_clusters`  
输出：`/perception/tracks`

每个 Track 至少包含：稳定 ID、位置、速度、尺寸、协方差、年龄、命中次数、丢失次数和 `TENTATIVE/CONFIRMED/COAST` 状态。

### 3.4 `track_roi_node`

输入：`/inno_lidar_cloud` + `/perception/tracks`  
输出：`/perception/track_rois`

职责：按 stamp 配对原始帧与 Track，将 AABB 向外扩张，从完整点云裁剪目标，按 Track 做 3～5 帧运动补偿累积，并统一采样为固定点数。

### 3.5 `object_classifier_node`

输入：`/perception/track_rois`  
输出：`/perception/classified_objects`

输出包含：Track ID、类别、每类概率、置信度、运动状态、位置、速度、尺寸和轨迹。

## 4. 分类输入原则

分类器输入使用 ROI 内完整点云，而不是仅使用 Moving Points。建议输入：

```text
N × [relative_x, relative_y, relative_z, intensity]
附加结构化特征：[length, width, height, point_count, vx, vy, vz]
```

ROI 默认扩张量先设为水平 0.4 m、垂直 0.2 m，必须通过真实数据调整。目标离开当前差分区域或短暂停止时，由 Track COAST 和历史 ROI 维持连续性。

## 5. 降级规则

- 背景未初始化：输出状态 `NOT_READY`，不得输出伪移动目标。
- 当前帧无移动点：已有 Track 可进入 COAST，不能立即删除。
- 分类器无结果：Track 继续输出，类别为 `UNKNOWN`。
- 分类置信度不足：保持 `UNKNOWN`，不强制归入已知类别。
- 分类节点崩溃或 GPU OOM：背景减除、聚类和跟踪继续运行。

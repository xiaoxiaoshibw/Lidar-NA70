# 02 分阶段实施计划

## P0 本机最小运动识别

任务：

1. Luna审查并补齐 `na70_motion_detector` 的ROS无关核心。
2. 增加一条不依赖ROS2的离线演示入口，产生静态背景和移动目标并输出逐帧状态。
3. 测试背景学习、静止场景、运动出现、短时噪声、连续确认和状态清除。
4. 固定第一版输出语义：`has_motion`表示相对启动背景出现了持续变化，不等同于完整物理速度估计。

退出条件：Windows本机可一条命令运行离线演示，自动测试全部通过，输出能从CLEAR切换到MOTION再恢复CLEAR。

## P1 WSL2/Humble ROS2冒烟测试

任务：

1. 在D盘安装 `Ubuntu-22.04` WSL2和ROS2 Humble，使本机测试环境与Jetson ROS发行版一致。
2. 在WSL ext4工作区构建 `na70_motion_detector`，源码可链接到 `/mnt/d/Code/radar/ROS2/src/na70_motion_detector`。
3. 运行合成PointCloud2发布器，验证 `/motion_detector/has_motion`、`moving_count`、`moving_ratio`和`moving_points`。
4. 验证QoS、空点云、缺失intensity、背景重置服务和节点退出。
5. 保存构建命令、Topic证据和结果摘要。

起始参数：`voxel_size=0.15 m`、`background_frames=100`、`background_min_hits=3`。这些仅是初值，真实数据验收后才能冻结。

退出条件：WSL2/Humble中 `colcon build`、launch、合成点云和全部Topic通过。本机x86_64结果仍不能替代Jetson ARM和真雷达验收。

## P1.5 WSL2真实PCAP回放

任务：

1. 在WSL2/Humble构建 `double_wedge_driver` 和 `na70_motion_detector`。
2. 启动UDP驱动、点云合并节点和运动检测节点。
3. 使用 `/mnt/d/Code/radar/tools/replay_pcap.py` 回放 `radar_capture_data/1.pcap`、`2.pcap`。
4. 确认 `/inno_lidar_cloud` 约10 Hz，并记录运动状态和候选点云。
5. 若PCAP没有明确运动真值，只验证链路和误报，不宣称真实运动检出率。

退出条件：PCAP能从UDP进入驱动并到达检测节点；输出、配置和日志可复现。

## P2 聚类和三维框

任务：

1. DBSCAN 聚类，初值 `eps=0.5 m`、`min_samples=8`。
2. 过滤地面噪声、小簇、异常尺寸和孤立高点。
3. 输出质心、AABB、特征和 Marker。
4. 处理一个人被拆簇、多人被合簇的问题。

退出条件：单人、多人与交叉场景有可回放证据；聚类数量、漏簇和误簇有统计结果。

## P3 多目标跟踪

任务：

1. Constant Velocity Kalman Filter。
2. 距离、尺寸和预测位置联合门控。
3. Hungarian 全局匹配。
4. 实现 `TENTATIVE → CONFIRMED → COAST → DELETED` 生命周期。
5. 保存有限长度轨迹并计算速度。

退出条件：已知轨迹单测通过；多人交叉、短时遮挡和背景吸收时 ID 连续性达到验收要求。

## P4 ROI 数据导出

任务：

1. 缓存最近原始点云并按 stamp 与 Track 配对。
2. 扩张 Track AABB，裁剪原始完整点云。
3. 按速度补偿并积累最近 3～5 帧。
4. 统一采样 256/512 点，保存 XYZ、intensity 和结构化特征。
5. 自动导出待标注 Track 样本与预览。

退出条件：抽检 ROI 能覆盖完整目标，目标点占比可接受，数据导出不存在训练/测试泄漏。

## P5 分类基线和点云模型

任务：

1. 明确第一版类别：`PERSON/BICYCLE/VEHICLE/OTHER`。
2. 先用尺寸、点数、反射率、速度等特征建立可解释基线。
3. 再训练轻量 PointNet 类 ROI 分类器。
4. 输出 ONNX，并在 Jetson 上验证 TensorRT 或其他可用推理后端。
5. 加入低置信度 `UNKNOWN` 和类别概率时序平滑。

退出条件：按录制序列隔离的测试集上提交混淆矩阵、每类 P/R/F1、Macro-F1、推理延迟和内存数据。

## P6 系统集成

任务：

1. 完成一键 launch 和统一 YAML。
2. RViz 同时显示 Moving Points、Cluster、Track、类别和轨迹。
3. 进行丢帧、延迟、分类器退出和 GPU OOM 故障注入。
4. 完成至少 30 分钟长测。

退出条件：主链稳定、类别不闪烁、分类器故障不破坏运动跟踪、资源峰值有记录。

## P7 可选完整点云 Detector

只有当需求扩展到“长期静止目标也必须分类”时才启动：

```text
完整点云 → 自定义数据训练的 3D Detector → Box/Class
Track → Box 关联 → 统一对象
```

公开 KITTI 权重只能用于部署链路试验，不能作为 NA70 正确性证据。
